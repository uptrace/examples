# examples

Runnable examples of sending data from Sentry SDKs to [Uptrace](https://uptrace.dev).
Each example is named after its framework or platform.

| Example | Description |
| --- | --- |
| [react](react) | A minimal React (Vite + TS) todo app instrumented with `@sentry/react`, sending errors, breadcrumbs and spans to Uptrace. |

Each example has its own `README.md` with setup and run instructions.
